Redesign Steam.

Build a working multi-page website that reimagines the Steam experience:

- Steam Home (Store)
- Game Detail
- Community
- About
- Support

The five pages should connect through a shared navigation so the result reads
as one coherent product.

WHAT EXISTS TODAY

Desktop screenshots of the current Steam site are supplied as reference. They
show the product as it is now: its pages, its content, the information each
page carries, and the design being reconsidered. Reusable imagery from the
Game Detail page is supplied alongside them.

Only desktop screenshots are provided. Decide for yourself what the experience
should become on smaller screens.

WHAT THIS EXERCISE IS ACTUALLY TESTING

This is a redesign, not a reproduction. Reproducing what the screenshots
already show would miss the point entirely.

The feedback above is the brief. Read it as a designer would: work out what
these people are actually struggling with underneath the tone, decide which
complaints share a root cause, judge which ones are worth acting on, and let
that reasoning drive the interface you build.

Deciding what to change, what to leave alone, and why is the substance of the
task. Two designers given this feedback should not arrive at the same website.

Steam remains Steam: the same store, the same catalogue, the same kinds of
information on each page. What the pages look like, how they are organised, how
dense they are, how someone moves through them, and what the interface chooses
to show first are all yours to reconsider.

Keep each page genuinely useful. A store page still has to sell a game, and a
support page still has to resolve a problem. Information density is a design
decision here, not a defect to be minimised away.

BUILD IT PROPERLY

Make it a real, working website rather than a static picture of one. Navigation
should work. Interactive elements should do something. The result should hold
up when someone actually clicks through it on a desktop and on a phone.
